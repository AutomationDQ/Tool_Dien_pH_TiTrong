Điền pH & tỉ trọng vào danh sách công ty

Thả phiếu xét nghiệm (.xls) và file công ty (.xlsx), đủ 2 file là tool tự chạy. Chỉ điền khi họ tên khớp; tỉ trọng 3 số lẻ, pH 1 số lẻ, không làm tròn. File kết quả tự lưu vào thư mục bên dưới.

Lưu vào: …
STTDòngHọ tên (file công ty)Họ tên (phiếu)Tỉ trọngpHTrạng thái

App chạy trên máy bạn (127.0.0.1), không gửi dữ liệu ra ngoài. Đóng cửa sổ đen (terminal) để tắt app. Nếu báo không tìm thấy số liệu: mở phiếu xét nghiệm trong Excel → Data → Edit Links → Update Values, lưu lại rồi chạy lại.
